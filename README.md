# Jump King

C++ / Direct2D로 만든 **정밀 점프 플랫포머** 클론 프로젝트입니다. Actor–Component–Scene 구조의 커스텀 게임 엔진을 직접 설계하고, 그 위에 "차징 점프"로 한 칸씩 올라가는 핵심 플레이를 구현했습니다.

> ⚠️ 이 프로젝트는 Nexile / Nerdok의 상업 게임 *Jump King*을 참고하여 만든 **개인 학습·포트폴리오 목적의 비공식(fan-made) 프로젝트**입니다. 상업적 이용 의도가 없으며, 원작과는 무관합니다.

## 소개

가만히 서 있으면 아무 일도 일어나지 않습니다. **Space를 눌러 점프를 충전**하고, 충전된 양만큼 더 높이·더 멀리 뛰어오릅니다. 한 번 잘못 뛰면 다시 바닥까지 굴러떨어질 수 있는, 실수에 관대하지 않은 등반형 플랫포머입니다.

## 주요 기능

- **차징 점프 물리**: Space를 최대 0.6초(35단계) 충전해 점프 세기를 조절, 충전량에 따라 점프 각도(최대 60°)와 방향도 함께 결정
- **벽/천장 반사**: 벽에 부딪히면 반발계수를 적용해 튕겨 나감
- **재질별 슬로프**: 일반/얼음/눈 지형마다 다른 마찰력으로 미끄러짐
- **경착륙 경직**: 높은 곳에서 떨어지면 잠시 움직일 수 없는 페널티
- **환경 시스템**: 비/가랑비/눈/가랑눈 날씨, 사인파 기반 바람, 스크롤되는 배경 구름·새, 장식 소품, 페이드인/아웃되는 히든월
- **씬 흐름**: 타이틀(Main) → 본편(Game) → 엔딩(Ending)
- **43개 레벨**을 JSON 데이터로 구성 (`Data/levels.json`)

## 조작법

| 키 | 동작 |
| --- | --- |
| ← / → | 좌우 이동 (점프 충전 중에는 점프 방향 조절) |
| Space (홀드) | 점프 충전 → 뗄 때 점프 |
| C | 노클립(자유 비행) 디버그 모드 토글 |
| ↑ / ↓ | 노클립 모드에서 상하 이동 |
| F1 | 콜라이더 디버그 표시 토글 |

## 기술 스택

- **언어**: C++20 (`std::format`, `std::filesystem`)
- **그래픽/사운드**: Direct2D, DirectWrite, WIC(PNG 디코딩), DirectSound
- **빌드**: Visual Studio 2022 (v143 툴셋), Windows 10 SDK

## 프로젝트 구조

```
JumpKing/
├── Engine/      # 입력, 렌더링, 리소스, 사운드, 타임, 디버그 렌더러 등 엔진 코어
├── Framework/   # Actor / Component / Scene / SceneManager / CollisionManager
├── Game/        # Player, MainScene/GameScene/EndingScene, 날씨·바람·스크롤·소품·히든월
├── Data/        # levels.json, images.json (레벨·리소스 메타데이터)
├── Resource/    # 스프라이트, 폰트, 사운드 등 실제 에셋
└── Json/        # JSON 파싱 라이브러리 (nlohmann/json)
```

엔진은 `Framework`의 `Actor`/`Component`/`Scene`을 기반으로 하고, `Engine`이 렌더링·입력·리소스 같은 저수준 시스템을, `Game`이 실제 플레이어·씬·레벨 로직을 담당하는 구조입니다.

## 빌드 방법

1. Visual Studio 2022 (Desktop development with C++ 워크로드) 설치
2. `JumpKing.sln`을 열기
3. 구성을 `Debug` 또는 `Release`, 플랫폼을 `x64`로 설정 후 빌드

## 라이선스

별도의 오픈소스 라이선스를 지정하지 않은 개인 학습·포트폴리오용 비공식 프로젝트입니다. 리포지토리에 포함된 스프라이트·폰트·사운드 등 에셋의 저작권은 원저작자에게 있을 수 있습니다.
